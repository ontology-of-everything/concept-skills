# Transcription Sources

The semantic and notation sources are summarized in `spec-format.md`. This repository additionally
requires one authoritative location per model element, application-wide arguments in the overall
PRD, and acceptance provenance back to an OP, application scenario, or behavioral case. These are
documentation conventions, not claims from the cited papers.

Use [Concept Purposes and Synchronization](https://essenceofsoftware.com/posts/distillation/) for
purpose relationships, [Jackson 2015](https://groups.csail.mit.edu/sdg/pubs/2015/concept-essay.pdf)
for purpose/OP arguments, and [WYSIWID](https://arxiv.org/abs/2508.14511) for the current record and
causal synchronization semantics.
