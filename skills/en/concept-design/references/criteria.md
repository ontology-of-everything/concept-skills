# Concept qualification

Check all eight against scenarios and counterexamples; record evidence for each conclusion.

| Criterion | Question |
| --- | --- |
| User-facing | What behavior does a user experience? API programmers count as users. |
| Semantic | What does the behavior mean? A color or widget alone is insufficient. |
| Independent | Can it be understood without another concept? Comment may use a target identity without defining Post. |
| Behavioral | What can users do and obtain? Object properties alone are insufficient. |
| Purposive | Does it serve one independently valuable need? A step may belong to a larger concept. |
| End-to-end | Does it reach the useful result? Authentication needs verification, not registration alone. |
| Familiar | Can users reuse prior knowledge? Prefer familiar behavior or justified variants; novelty alone is not a defect. |
| Reusable | Can its meaning work elsewhere? Existing reuse does not establish the other criteria. |

Classes, tables, deployment units, and individual stories MUST NOT determine the boundary.
