# Settle a discussion

1. State goals, scope, constraints, and changes.
2. Summarize concept purposes and key scenarios.
   Expand state, actions, OPs, instances, bindings, and rules only as needed for the decision.
3. For each consequential choice, use the [decision record](decisions.md).
4. Ask only about unresolved choices affecting the requested work.

Include table, interface, or service mappings only when they affect a choice.
Distinguish required behavior from implementation choices.
