# 同步规格

按[规格契约](spec-format.md)新建或回填因果规则，匹配完成动作，查询公开状态，用已绑定值调用声明动作。
文档分组不是运行时 flow 身份，请求、定时和消息须各有入口契约。

## 确定规则

从应用目的和场景定位入口完成、成功/错误分支、绑定、输出、响应义务、对象/请求关联、部分完成、重放与循环。
一条规则表达一项可解释决定。动作原子维护不变量，查询不能代替写入检查。

回填追踪处理器、注册、mediator 和适配器到公开动作，标明推定意图与缺陷。
概念互调或私有 SQL 访问不能因转录就变成合法同步。纯数据转换归 PIPELINE，复杂模型取舍交设计。

## 完成检查

每个 composition 一份 SYNCS，按入口或职责分组，规则身份唯一。
解析 include、实例、动作/查询签名和调用参数，保留零/多结果含义、请求隔离及全部可达结果的响应、重试、补偿或忽略策略。
循环须终止或受控持续运行，深度上限只是可选保护。

报告规则数、场景覆盖、边界发现和未知项，缺失目的保持未决。
图保留合取触发、多目标与查询边，迁移保留行为。hooks 只列 SYNCS，不检查语义。
