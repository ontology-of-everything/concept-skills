# 漂移检测

默认只读对比确认契约与当前实现。历史按明确请求保存，drift 不修复规格或代码。

## 取证与边界

读规格、PRD/暂存索引、相关规则、代码、schema/迁移与测试。搜索后检查定义，祖先覆盖须有内容依据。
实现缺失或未读完整时标未核实。

确认架构与语义漂移分别检查。默认基线核对独立构建、同进程装配、api/composition/concept 边界、概念独立性、端口与适配器，以及已采用的 Clean 分层。
server 可用公开工厂。不把默认结构强加给旧项目，也不凭目录或无环图证明边界。

## 类别

| 契约 | 差异 | 默认严重度 |
| --- | --- | --- |
| CONCEPT | 未记录公开动作、签名或结果变化、新的可观察状态、未记录的契约参数 | Medium |
| CONCEPT | 已声明动作在全部相关实现中不存在 | High |
| CONCEPT | 私有访问、概念互调、共享可变状态、排除动作仍可达 | High |
| CONCEPT | 核心定义依赖另一概念，或混入旧边界段 | Medium |
| CONCEPT | OP 缺少代表性测试 | Medium，验证缺口 |
| CONCEPT | 已记录缺口被当前实现解决 | Low |
| PIPELINE | 遗漏阶段或来源，数据契约变化 | Medium |
| PIPELINE | 不变量矛盾，跨概念私有访问 | High |
| SYNCS | 遗漏规则，触发变化 | Medium |
| SYNCS | 删除规则、未声明参与者、绑定或效果变化 | High |
| 地图 | 已有图与规则矛盾 | Medium |
| 引用 | 动作或 query 不存在，签名、结果、类型绑定不符 | High |
| 引用 | 内部概念既无规格也无索引说明 | Medium |

管道检查顺序、数据契约、触发、质量与公开接口。同步检查分支、查询行数、调用、关联、失败、重放与循环。
外部入口须有签名，Requesting 不必有虚构的 CONCEPT。产品依赖取自 PRD 需求，同步图可只放在那里。

## 严重度校准

Critical 须有权限绕过、数据破坏或核心不可用证据。High 为明确违约，Medium 为有影响遗漏，Low 为局部维护。
调整默认值须说明理由，Medium 及以上附当前位置。同一根因合并并列受影响路径。

规格沉默不证明禁止。私有辅助函数/缓存、命名映射、保持行为的 Result/异步包装本身不是漂移。
公开状态可读。OP 缺测试是验证缺口，目的落空须另附反例。记录概念互调不表示独立性恢复。
旧记法按[规格契约](spec-format.md)兼容。

## 报告与可选历史

说明范围/版本、计数、每类通过/发现/未核实、契约/代码位置、影响与修复步骤，分批后核对跨规格引用。
模型问题交设计，文档陈旧交 PRD/规格维护，代码违约交实现。行为未定时呈现取舍，不默认跟随代码。
修复使用相应写入模式。

仅按明确请求追加 `.claude/wyx-drift-history.jsonl`：

```json
{"ts":"<ISO-8601>","action":"detect","specs_scanned":0,"specs_with_drift":0,"critical":0,"high":0,"medium":0,"low":0,"low_by_spec":{},"path":"<范围>"}
{"ts":"<ISO-8601>","action":"fix","specs_fixed":0,"specs_remaining":0,"ref_ts":"<对应 detect 时间>"}
```

使用实测计数，仅无剩余发现的规格计入 fixed。fix 关联 detect，不改旧行，无 action 的旧记录按 detect 理解。
运行时只读最后快照，局部结果不代表全仓，须重新扫描才可清除陈旧提示。
不伪造零漂移，也不因 Low 数量多就升级。
