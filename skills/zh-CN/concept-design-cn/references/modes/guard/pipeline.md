# 数据质量规格

跨概念协调归 SYNCS。

```markdown
# pipeline: Name
## purpose
<使用方与所需结果>
## sources
<来源、拥有者、粒度、契约>
## stages
### Stage [tool: <实际工具>]
<输入/模式 → 转换 → 输出/模式>
<质量检查与失败后果>
## outputs
<产物、模式、拥有者、使用方>
## invariants
<可检查规则与验证方式>
## triggers
<事件、API、定时或手动入口>
## data boundary
<拥有者与允许的公开读写>
```

从命令、工作流、模式、查询/连接和检查回填。
每个来源、阶段、输出与不变量 MUST 对应代码或明确的待实现契约。
概念 SQL 适配器不授权管道跨概念访问私有存储。
`score in [-1, 1]` 可检查；“数据干净”不可检查。
行数限制须有契约依据。
新流程还须说明追加/刷新和幂等行为。
