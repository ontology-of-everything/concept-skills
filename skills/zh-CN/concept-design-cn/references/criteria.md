# 概念资格

用场景与反例检查全部八项；每项结论记录证据。

| 判据 | 问题 |
| --- | --- |
| 面向用户 | 用户体验到什么行为？API 程序员也是用户。 |
| 语义性 | 行为有什么含义？颜色或控件本身不够。 |
| 独立性 | 不读另一概念能否理解？评论可使用目标身份，无需定义帖子。 |
| 行为性 | 用户能做什么、得到什么？对象属性本身不够。 |
| 目的性 | 是否服务一个有独立价值的需要？某步骤可能属于更大概念。 |
| 端到端 | 是否达到有用结果？认证须能验证身份，不能只有注册。 |
| 熟悉性 | 能否沿用经验？优先熟悉行为或有依据的变体，新颖本身不是缺陷。 |
| 可复用性 | 同一含义能否用于别处？已有复用不证明其他判据成立。 |

类、表、部署单元或单条用户故事 MUST NOT 决定概念边界。
