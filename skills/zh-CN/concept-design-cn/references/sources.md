# 设计依据

| 来源 | 用途 |
| --- | --- |
| [概念目的](https://essenceofsoftware.com/posts/distillation/) | 应用可有多个目的，每个概念有自己的目的，同步协调概念。 |
| [Jackson 2015，第 8、9 节](https://groups.csail.mit.edu/sdg/pubs/2015/concept-essay.pdf) | 运作原理解释目的，反例检验论证。 |
| [Beyond Objects 第 13 节](https://arxiv.org/abs/2606.27258) 与 [WYSIWID 第 4 节](https://arxiv.org/abs/2508.14511) | 概念规格与因果同步，区别于旧事务同步。 |
| [资格](https://essenceofsoftware.com/tutorials/concept-basics/criteria/)、[组合](https://essenceofsoftware.com/tutorials/concept-basics/sync/)、[依赖](https://essenceofsoftware.com/tutorials/concept-basics/dependency/) | 八项资格、欠/过同步、内在/外在依赖与子集。 |
| [设计手法](https://essenceofsoftware.com/posts/design-moves/)与[课程 rubric](https://61040-fa25.github.io/resources/concept-rubric) | 拆分/合并、统一/特化、收紧/放松及应用备注。 |

[本仓契约](spec-format.md)规定记法，标明相对 WYSIWID v1 的查询与入口扩展。
流程、对齐部分、目的论证和规则节点图属于本仓约定。
运作原理说明代表性结果，它与目的论证都不证明全部行为。
