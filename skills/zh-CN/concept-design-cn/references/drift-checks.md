# 漂移与严重度

只读比较适用确认契约与当前实现，不修复。
读规格、PRD/暂存索引、规则、代码、模式/迁移和测试。
搜索后检查定义；祖先覆盖须有内容依据。
缺失/未扫描代码标未核实。
记法与行为按[规格记法](spec-notation.md)核对。

## 分类

| 证据 | 默认严重度 |
| --- | --- |
| 未记录公开动作、签名/结果变化、新可观察状态、未记录契约参数 | Medium |
| 声明动作在全部相关实现中不存在 | High |
| 核心定义在语义上依赖另一概念 | Medium |
| 私有访问、概念互调、共享可变状态、排除动作可达 | High |
| OP 缺代表性测试 | 验证缺口，按风险 |
| 已记录缺口被实现解决 | Low |
| 未记录规则 / 声明规则删除 | Medium / High |
| 触发变化 | Medium |
| 绑定/效果变化、未声明参与者、匹配/关联/基数错误、缺必需响应、非法共同效果、禁止重放、不变量错位 | High |
| 场景证明欠同步、失去控制、目的偏离或协调状态出现独立业务生命周期 | Medium |
| 必需进展或授权一致性不成立 | 按影响 |
| 全部支持入口均证明无法触发规则 | Low |
| PIPELINE 缺阶段/来源、数据契约变化 | Medium |
| PIPELINE 不变量矛盾/私有访问 | High |
| 现有地图与规则矛盾 | Medium |
| 动作/查询/签名/结果/类型绑定未解析 | High |
| 内部概念缺规格/索引说明 | Medium |

检查管道顺序、契约、触发、质量和公开接口。
检查规则分支、查询基数、参数、关联、失败、重放和循环。
解析外部入口签名；Requesting 无需虚构 CONCEPT。

## 判定与报告

先确定基线确认状态和覆盖范围。
局部模型未声明的行为是覆盖缺口，除非适用契约或明确排除能证明漂移。
私有辅助函数/缓存、命名映射、保持行为的 Result/异步包装和旧标题本身不是漂移。
已记录例外保留范围/后果；记录互调不恢复独立性。

Critical 须有权限绕过、数据破坏或核心不可用证据。
High 为明确违约，Medium 为有影响遗漏，Low 为局部维护。
按影响调整须解释；Low 数量不自动升级。
Medium 及以上发现 MUST 引用当前位置。
跨路径合并共同根因。
报告范围/版本、实测计数、逐类通过/发现/未核实、契约/代码位置、影响和修复步骤。
