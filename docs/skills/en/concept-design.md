# Concept Design

`concept-design` is an explicit-only workflow for completing a concept design with the user:
confirm the alignment, then write the design record and test both concept-purpose and
application-purpose arguments.

- Skill: [SKILL.md](../../../skills/en/concept-design/SKILL.md)
- Chinese: [`concept-design-cn`](concept-design-cn.md)

```bash
npx skills add ontology-of-everything/concept-skills --skill concept-design
```
