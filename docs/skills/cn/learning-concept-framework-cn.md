# 概念框架学习（Learning with Conceptual Frameworks）

目的：把学习者的目标转成可检验的关键框架，使新资料能按概念归位、质疑并修正框架，逐渐形成可复用的模型树。“目标定性”就是立关键框架。支持自动匹配与显式调用。

```text
$learning-concept-framework-cn 我想判断一种肥料是否促进植物生长，请把相关资料组织成模型树。
```

[SKILL.md](../../../skills/cn/learning-concept-framework-cn/SKILL.md) · [QA](../../../qa/cn/learning-concept-framework-cn/README.md)

## 选择规则

按用户要求的结果判别，不按“概念”关键词匹配：

| 要求的结果 | 路由 |
| --- | --- |
| 学习新领域，先明确目标与关键框架 | 本技能：形成初始框架 |
| 将多本书、课程、文章整合为知识体系 | 本技能：按概念吸收知识 |
| 将按作者目录摘抄的笔记重构为知识树 | 本技能：按学习目标重新组织 |
| 按原文结构概括资料 | 普通摘要 |
| 从原文抽取场景、概念、实体 YAML | `semantic-pkm-creator` |
| 设计软件概念、状态、动作与同步 | `concept-design` |

## 产物

交付 `learning-framework-<topic>.md`，保留四个可追溯的层次，并按资料情况加入正反案例：

| 部分 | 必须回答 |
| --- | --- |
| 目标 | 要解决什么问题？怎样算达标？ |
| 目标定性／关键框架 | 实现目标需要哪些因素及关系？为何选这个框架？给定资料如何支持或反驳它，是否覆盖目标？ |
| 概念与关系 | 框架下各概念起什么作用、怎样互相影响？注明资料依据或推断。 |
| 有出处的知识 | 方法、误区、案例归于哪个概念，为什么？原文或其他来源是什么？ |
| 经典正反案例（若有） | 哪个案例达成目标、哪个失败？各自结果和机制是什么，归于哪个概念，出处与适用边界是什么？资料缺失则列为待补。 |

若原文已有适配框架，可复用并说明其怎样实现目标；但原文目录本身不自动成为模型树主干。对每个框架分支都要查给定资料，标出支持、反证或缺口。完备性相对于当前目标判断，正确性接受证据和反例检验。正反案例优先选目标与条件可比较、来源可核实的经典案例；条件差异影响判断时，注明不可直接类比。

## 经典案例：对照实验

“学习植物生长”只是主题；“判断某种肥料是否使幼苗长得更快”才是可检验的目标。它是因果判断问题，因此**对照实验**是候选关键框架：处理组与对照组在其他条件尽量一致时比较同一结果指标。这里演示的是框架选择，未提供实验数据，不宣称肥料有效。

```text
目标：判断某种肥料是否影响幼苗生长
└─ 目标定性／关键框架：因果判断；比较处理组与对照组［对照实验］
   ├─ 概念：处理——是否施用该肥料
   │  └─ 资料中的施用方式［出处、归属理由］
   ├─ 概念：受控条件——光照、水分、土壤等尽量一致
   │  └─ 资料中的环境要求［出处、归属理由］
   ├─ 概念：结果——固定时间内的生长量
   │  └─ 实际测量数据［来源、测量方式］
   └─ 关系：两组结果的差异才用于检验肥料影响［待数据验证］
```

## 正反判别

下表展示的是构树方法的正反示意，不是肥料效果的实验结论。

| 检查 | 正例 | 反例 |
| --- | --- | --- |
| 主干从何而来 | 从因果目标推出处理、对照、受控条件和结果。 | 把资料的种植步骤直接列为主干，却无法判断肥料有无作用。 |
| 框架是否适配 | 解释每个因素对比较的必要性，并查资料是否支持具体设计。 | 只因“对照实验”常见就套用，却没有可比较的组或结果。 |
| 新知识如何处理 | 将施用建议、环境条件、测量记录按作用归位；若光照不一致，修正设计或结论。 | 没有数据便断言有效；出现反例仍保留原结论。 |
