# Changelog

- 增加销售模型树的正反判例：框架因素先检验目标作用与资料依据，作者目录不得直接当主干，不适配知识触发框架复核。

## 0.2.1

## 0.2.0

- 更名为 Learning with Conceptual Frameworks（`learning-concept-framework`）；区分学习、摘要、抽取与软件设计，明确学习框架文档及验证要求，正文较初始版本保持精简超过 50%。
- 明确目标定性、学习场景与目标→概念→知识树产物，要求出处和归属理由，保留框架复用及验证。
